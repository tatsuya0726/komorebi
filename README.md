# こもれび

[アプリを開く](https://tatsuya0726.github.io/komorebi/)

夜の一言を残し、自分のペースで過ごすための小さなWebアプリ。メンズメイク・美容のガイドと、娯楽としての日替わり占いがあります。

## 2026-10-09 更新

- 木漏れ日・美容の道具・星空の画像3点と、PC・スマホ対応の新しい画面。
- 占いは全体運、仕事・学び、人間関係、自分時間、身だしなみ、ラッキーカラーの6項目。端末の現地日付で更新する、全員共通の創作メッセージです。
- ユーザー指定の名言Botシートから、名言と人物名9件を取り込み。初回ランダム表示と、直前の名言を避ける切り替えボタン。人物名・文言はシート準拠で原典未照合。送信済みフラグなどは含めません。
- 名言は2026-10-09時点のスナップショット。シートの変更は自動反映されません。quote-data.jsの更新が必要です。

## 保存とプライバシー

保存なし、または端末内保存を選べます。記録を外部へ送信しません。同じ所有者のGitHub Pagesは保存領域を共有し得ます。診断・治療・未来予測を行うものではありません。占いは健康や金銭の判断に使用しないでください。

画像は内蔵画像生成ツールによるイメージで、掲載商品の実物ではありません。生成プロンプトと保存先はIMAGE-NOTES.mdを参照。

## 公開・検証

ビルド不要。GitHub Pagesのmainブランチ、ルートフォルダから公開。
既存画面テスト5本に加え、320/390/1440px、名言の連続重複回避、占いの日付跨ぎ更新、画像読み込み、途中記録の保持と外部送信なしを確認。実機Safari・VoiceOverは未確認です。

## 成長の採点

「成長記録」の「今日1日の成長」から17項目と0〜100点（10点刻み）の尺度を取り込みました。人4項目、行動7項目、思考3項目、健康3項目。分野ごとの全項目が入力されると平均点を表示し、4分野の平均の合計を400点満点で表示します。未入力と0点は区別し、途中保存も可能。同じ採点日は更新します。

採点結果と途中入力は既存の保存設定に従い、JSON書き出し・単件削除・全消去にも対応。従来の記録との互換性を維持します。シートへの書き戻しや自動同期、過去の採点結果の取り込みはありません。

採点の単体テスト5件、320/390/1440pxでのブラウザ検証、保存・更新・削除・書き出し・日付跨ぎ・既存記録保持の確認が成功。既存の画面テスト5本とデザイン追加テストも成功。
