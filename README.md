# こもれび

夜の一言を残し、自分のペースで過ごすための小さなWebアプリです。メンズメイク・美容のガイドと、娯楽としての日替わり占いがあります。

ビルド不要。GitHub Pagesのmainブランチ、ルートフォルダから公開できます。

## 記録の保存

保存なし、または端末内保存を選べます。記録を外部へ送信しません。同じ所有者のGitHub Pagesは保存領域を共有し得ます。共有端末での利用にも注意してください。診断や治療、占いによる未来予測を行うものではありません。
